# Release Candidate v2.19.0-rc.1

Data: 2026-09-12

## Status

**Release candidate — NO-GO para produção.**

Esta versão consolida o ciclo de integração do Inventário/Motor de Ativos com o Sistema de Despacho e prepara o pacote para homologação externa real. A promoção para release final depende da conclusão do issue #97 e do encerramento do ciclo R1 no issue #89.

## Principais entregas

- integração REST do Despacho com o Motor de Ativos;
- busca, detalhe, localização e vínculo contextual de ativos;
- timeline/prontuário e referências externas;
- consumo versionado de eventos do Inventário;
- replay/idempotência e rejeição fail-closed de versão incompatível;
- isolamento multi-tenant e autorização negativa cobertos por testes;
- adaptador seguro `/homologation/events`, indisponível por padrão e não registrado em produção;
- harness externo de homologação com relatório JSON/Markdown e correlation IDs;
- workflow manual protegido por GitHub Environment `homologation`;
- runbook operacional R1 para sessão externa e rollback.

## Evidência de CI antes desta RC

Nos ciclos M16/R1 anteriores foram validados segurança, TypeScript, suíte de testes, build, Docker, GIS e compatibilidade/visual NEO. A RC deve repetir os gates no HEAD final antes do merge.

## Tentativa de homologação externa real

Foi executada uma tentativa real em 2026-09-12 pelo workflow temporário `Inventory external homologation once`, run `34726884023`, vinculada ao PR #98.

Resultado: **FAIL no preflight**.

O GitHub Environment `homologation` entregou vazios os parâmetros obrigatórios. O primeiro erro explícito foi:

`Configuração obrigatória ausente: ASSET_MOTOR_BASE_URL`

Também estavam vazios `DISPATCH_BASE_URL`, tenants A/B, usuário, ocorrência e `HOMOLOGATION_AUTH_TOKEN`.

Consequências:

- nenhuma chamada foi feita ao Motor de Ativos;
- nenhuma chamada foi feita ao Despacho de homologação;
- nenhum dado de negócio foi alterado;
- nenhum deploy, migration ou grant produtivo foi executado;
- o PR operacional #98 foi encerrado sem merge.

## Gate para promoção a release final

A RC só poderá ser promovida quando o GitHub Environment `homologation` estiver configurado e uma sessão real comprovar:

- busca, detalhe e localização de ativo;
- vínculo ocorrência ↔ ativo;
- isolamento entre tenant A e tenant B;
- evento versão `1` processado;
- replay do mesmo `eventId` tratado como duplicado;
- versão incompatível rejeitada em fail-closed;
- rastreabilidade por `correlationId` no Motor e no Despacho;
- degradação controlada com Motor indisponível;
- rollback operacional auditável.

## Produção

Esta RC **não autoriza deploy em produção**. O estado permanece NO-GO até decisão explícita após homologação externa real aprovada.
